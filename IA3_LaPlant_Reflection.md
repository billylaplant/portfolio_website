## AI as a tool
Using Claude Code for this assignment was significantly quicker than writing python code by hand for IA2. Including debugging and testing time, this assignment took me about 6 hours. Without using Claude Code, the time to completion would have doubled. I found Claude Code to be the correct tool to create the website, with little difficulty completing the task. This surprised me, because I expected Claude to require a steep learning curve from my knowledge of it being a popular tool for developers. Being an intermediate-skilled developer, I caught on quickly. AI was most helpful in the plan and manual code writing stages, which were the methods I used to create the website. Even though I understood the instructions well, the plan allowed me to follow the Claude-created plan. One challenge I had with AI was describing each requirement without copying and pasting the input into the LLM. If it was not explicitly mentioned in the instructions to “not copy and paste this sheet into the agent”, I would have uploaded the document. Often, that is my practice and my co-workers’ practice in work-related and personal use of AI, and I think most situations there is no downside in uploading instructions. However, it is important to understand the instructions and carefully read what the responses and code are, because the LLM only knows what you share. Any context not shared will be assumed and often can lead to inaccurate results. One main issue I had was seeing the code written by Claude and asking Claude to describe the code. Sometimes, the code wasn't visible, or the explanation wasn't visible. I prompted Claude multiple times to add an explanation to the code so I would understand the reasoning before approving the code. It eventually added the description as a requirement, but the description seemed to disappear several times during the project. When creating my site, I believe I missed some opportunity for Claude or another LLM to find pictures for my projects. However, some pictures were screenshots and specific files that LLM did not have access to. Therefore, to ensure the accuracy of the project photos, human interaction was required.

## Process
Starting the assignment required understanding the instructions enough to explain them to another person (Claude Code, in this case). I began by summarizing and re-writing the instructions and asking for advice on the best stack choice. My goal was to write one prompt to make the plan and then use the .md file it created as my new instructions for Claude to follow. This method proved successful, but I added many steps during the process. This should be expected going forward, but I still believe setting the expectations and giving the LLM context (in this project, I told Claude Code it was a project personal assistant for my vibe-coding project) was key to the success of the project. Another change to my process during my Claude usage was when I identified that the LLM had not created a new GitHub repository. I gave Claude Code the markdown file from OE2 as an outline and example, which worked great. However, after about 5 prompts, I told it to stop and check whether it created a new project or not (and it had not yet). I had Claude Code explain why or why I was correct in my assumption and give next steps. I also was still learning the difference between Plan mode and Manual mode, and I was still in Plan mode at this time, so no changes had been made.

After completing this assignment, I am more familiar with Claude Code and how to use it within Visual Studio Code. I was skeptical that the source code editor would organize the LLM, terminal, folder structure, and files well, but going forward I plan to use the same tools for future projects. My dad, being a recently retired software developer, would have a different looking career if he started it now instead of in the 80’s. My understanding of his career, and this assignment utilizing Claude Code for 100% code writing, provides me with a perspective of two key aspects to a successful career in software development: accelerated development cycles and being able to quickly adapt to new tools. The contrast of AI tool usage between IA2 and IA3 proves that manual code writing still works, but using AI tools accelerates the process time. Knowing how to code has a new meaning when using Claude Code but understanding code and being able to explain the code does not change meanings. For example, your boss may ask you to explain how your code works in a meeting and field questions from the testing team. When I was taking CS classes at Purdue in my undergrad, I was instructed to use stack overflow when I needed help with my code. Now, the expectation is to use LLM to write the code and help with the code. In summary, AI is great at writing code, and I will continue to use the tool in future projects. However, proper prompt engineering will continue to be the required first step in a successful project.
